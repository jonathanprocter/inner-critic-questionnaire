# Inner Critic Questionnaire

This project is a simple self‑assessment tool that helps identify which of the seven common "inner critic" voices may be most active in your life. The questionnaire runs entirely in the browser and saves your progress locally so you can return to it later.

## Using the questionnaire

Open `index.html` in any modern web browser. The page works offline once loaded and no information is sent to a server. You can export your results as a PDF or share them via email from the results screen.

## GitHub Pages

The repository is ready for GitHub Pages. Enable Pages in your repository settings and select the main branch as the source. GitHub will host `index.html` as the site homepage, making the questionnaire available at `https://<your-user>.github.io/<repo-name>/`.
